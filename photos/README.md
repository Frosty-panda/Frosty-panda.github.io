# Portfolio photos

The site uses the image files in this folder. The small animal image stays in the top-left avatar; the professional portrait appears in the hero. The Photos section has view-only albums for each category.

Current image files:

- `animal.png` — small top-left avatar
- `professional.jpg` — professional portrait in the hero
- `american-express-1.jpg.jpg` — American Express album
- `arb-trading-group-1.jpg` — ARB Trading Group album
- `college-1.jpg` through `college-4.jpg` — College album
- `misc-1.jpg`, `misc-2.jpg` — Miscellaneous / trips album

`college-3.HEIC` is the original of the third college image. Use the generated `college-3.jpg` copy for the website so it displays in common browsers; keep the original if you want.

The Morgan Stanley album has empty slots until you add matching photos. The American Express and ARB albums each have a second empty slot. To add more images to an album, add the next numbered file and extend its image list in `index.html`.

When publishing, upload this entire folder alongside `index.html`, `styles.css`, and `script.js`. Visitors can view the albums but cannot upload or edit photos through the website.
